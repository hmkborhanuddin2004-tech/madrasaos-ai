# MadrasaOS AI (মাদ্রাসা ওএস এআই) — সংস্করণ ১.০.০
> **বাংলাদেশ মাদ্রাসা ম্যানেজমেন্ট + এআই এজেন্ট প্ল্যাটফর্ম**  
> কওমি, আলিয়া, হিফজ ও আবাসিক মাদ্রাসার জন্য তৈরি আধুনিক ডিজিটাল সমাধান।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **রোল-ভিত্তিক অ্যাক্সেস কন্ট্রোল (RBAC):**
   - **মুহতামিম / অ্যাডমিন:** মাদ্রাসার পূর্ণ নিয়ন্ত্রণ, কাস্টমাইজেশন, শিক্ষক নিয়োগ, অনুমোদন।
   - **শিক্ষক / ওস্তাদ:** ক্লাস হাজিরা, দরস ও সবক রুটিন, সিলেবাস ট্র্যাকিং, পরীক্ষার মার্কস এন্ট্রি।
   - **হিফজ শিক্ষক:** ৩০ পারা কোরআন ট্র্যাকিং, দৈনিক ছবক, সবকী ও আমুখতা (মঞ্জিল) মূল্যায়ন।
   - **হিসাবরক্ষক:** আবাসন ও অনাবাসন লেজার সেগ্রিগেশন, ক্যাশ বই, অনুদান (লিল্লাহ/এতিমখানা/ওয়াকফ), ব্যাংক জমা ও রশিদ।
   - **অভিভাবক:** সন্তানের প্রতিদিনের উপস্থিতি, পরীক্ষার রেজাল্ট, বকেয়া ফি ও মাসিক নোটিশ।
   - **শিক্ষার্থী:** নিজের হাজিরা, দৈনিক আমল ও মুহাসাবা হিসাব।

2. **প্রতিষ্ঠানের পূর্ণ কাস্টমাইজেশন (Admin Exclusive):**
   - মাদ্রাসার বাংলা ও ইংরেজি নাম, লোগো ও থিম রঙ পরিবর্তন।
   - কাস্টম ফি ক্যাটাগরি এবং নতুন জামাত ও কিতাব/বিষয় তৈরির সুবিধা।
   - নিজস্ব Google Gemini API Key এবং Brevo SMS/Email Key সেট করার প্যানেল।

3. **এআই অ্যাসিস্ট্যান্ট ও ডায়নামিক ভয়েস এজেন্ট:**
   - বাংলা ভয়েস কমান্ড এবং Google Gemini 2.0 Flash ইন্টিগ্রেশন।
   - রিয়েলটাইম লাইভ সাউন্ড ওয়েভ ইকুলাইজার (কোনো রেড সিগন্যাল ছাড়া প্রাণবন্ত টিয়া গ্রিন থিম)।

4. **লোকাল-ফার্স্ট ও অফলাইন PWA সমর্থন:**
   - কম্পিউটার (PC/Laptop), অ্যান্ড্রয়েড ফোন বা আইফোনে ১-ক্লিকে অ্যাপ হিসেবে ইনস্টল করা যায়।
   - SQLite WAL মোড ডাটাবেজ—ইন্টারনেট ছাড়াও লোকাল সার্ভারে প্রচণ্ড দ্রুত চলে।

## 🚀 নতুন কম্পিউটারে চালানোর সহজ নিয়ম (Quick Start Guide)

### ১. পূর্বশর্ত (Prerequisites)
- [Node.js](https://nodejs.org/) (সংস্করণ ১৮ বা তার উর্ধ্বে) ইনস্টল করা থাকতে হবে।

### ২. ডিপেন্ডেন্সি ইনস্টল (Installation)
প্রজেক্ট ফোল্ডারে টার্মিনাল বা PowerShell খুলে নিচের কমান্ডটি দিন:
```bash
npm install
```

### ৩. প্রজেক্ট চালু করা (Start Application)
ডেভেলপমেন্ট মোডে একসাথে ব্যাকএন্ড ও ফ্রন্টএন্ড রান করতে:
```bash
npm run dev
```
অথবা প্রোডাকশন বিল্ড তৈরি করে রান করতে:
```bash
npm run build
npm start
```

ব্রাউজারে গিয়ে ওপেন করুন:
- **ওয়েব অ্যাপ:** [http://localhost:3000](http://localhost:3000)
- **ব্যাকএন্ড API:** [http://127.0.0.1:5000](http://127.0.0.1:5000)
- **সার্ভার হেলথ চেক:** [http://127.0.0.1:5000/health](http://127.0.0.1:5000/health)

## 📁 ফোল্ডার স্ট্রাকচার (Directory Layout)
- `client/`: React 19, Vite, Tailwind CSS, Lucide Icons ফ্রন্টএন্ড কোড।
- `server/`: Node.js, Express, TypeScript, REST API ব্যাকএন্ড কোড।
- `server/src/db/`: ডাটাবেজ স্কিমা, মাইগ্রেশন ও সীড স্ক্রিপ্ট।
- `data/`: লোকাল SQLite ডাটাবেজ ফাইল (`madrasaos.sqlite`)।
- `tests/`: পূর্ণাঙ্গ টেস্ট স্যুট (RBAC, একাউন্টিং, ফি, নোটিফিকেশন ইত্যাদি)।
- `docs/`: টেকনিক্যাল আর্কিটেকচার ও ডকুমেন্টেশন।
